# ホールデム道場

テキサスホールデム（ノーリミット）を CPU 相手に打ちながら学べるブラウザアプリです。
ビルド不要で、`index.html` をブラウザで開くだけで動きます。

## ウェブサイトとして公開する（GitHub Pages）

`.github/workflows/pages.yml` が、push のたびにテストを実行してサイトを GitHub Pages に公開します。初回だけ次の設定が必要です。

1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** にする
3. **Actions** タブで「Deploy to GitHub Pages」を再実行する（または何か push する）

公開 URL は `https://dave-suzuki.github.io/de/` です。非公開リポジトリで Pages を使うには GitHub Pro 以上が必要です（無料プランの場合はリポジトリを公開にする必要があります）。

## 3つのモード

| モード | 内容 |
| --- | --- |
| **プリフロップ特訓** | 配られた2枚とポジションを見て、フォールド／コール／レイズを即答。答えるとすぐ採点して理由を解説します。「ヒントを見る」で先にアドバイスを見ることもできます。 |
| **ライブコーチ** | 1ハンドをリバーまで通してプレイ。自分の番になるたびに、推奨アクション・推定勝率・ポットオッズ・ドローを表示します。ハンド終了後には振り返りも出ます。 |
| **レビュー** | プレイ中のヒントはなし。ハンド終了後に、一つひとつの判断を「推奨」「こうすべきだった」「実際の勝率（相手の手札が見えていた場合）」と一緒に振り返ります。 |

各判断は「ナイス判断／許容範囲／改善しよう」で採点され、ヘッダーに累計の正解率と収支（BB）が出ます。
良い判断を続けるとコンボ、ポイントが貯まると段位（入門 → 5級 … 初段 … 名人）が上がります。

## 楽しむための仕掛け

- **キャラクター**：堅実なタケシ、攻撃的なミホ、コール好きのケン、バランスのサクラ、ルーズなゴロー。SVG で描いた似顔絵が、まばたき・考え中・レイズ・オールイン・フォールド・勝利で表情と動きを変えます。
- **見やすいアクション**：各キャラの行動は色分けした吹き出し（セリフ付き）で表示し、レイズやオールインはテーブル中央に大きくアナウンスします。チップはベット・回収・払い出しでテーブル上を移動します。コーチ欄には、そのラウンドの流れも一覧で出ます。
- **BGM と効果音**：Web Audio API でその場で合成しています（音声ファイルは使っていません）。BGM はスウィングするラウンジ・ジャズで、効果音はカード配り・チップ・チェック・フォールド・オールイン・勝利・採点・昇級などに付いています。ヘッダーで BGM・効果音・音量を切り替えられます。
- **用語の説明**：コーチの説明に出てくる用語（ポットオッズ、3ベット、セミブラフなど）は点線の下線付きで、タップすると説明が出ます。席のポジション表示（UTG、BTN など）もタップできます。サイドの「用語集」では全用語を検索できます。
キーボードでは F（フォールド）、C（チェック／コール）、R（ベット／レイズ）、N（次のハンド）が使えます。

## コーチの考え方

- **プリフロップ**：チェン・フォーミュラでハンドを点数化し、ポジション別の参加基準（UTG 9点、HJ 8点、CO 7点、BTN 6点…）で判断。レイズへの対応（3ベット／コール／フォールド）、BB のディフェンス、ポケットペアのセットマイニングも考慮します。
- **フロップ以降**：モンテカルロ法で推定勝率を計算します。相手のハンドは、プリフロップの行動（レイズ・コール・リンプ）から推定したレンジと、そのストリートでベットしたかどうかで絞り込みます。その勝率を、ポットオッズ・ドローのアウツ（2と4の法則）・インプライドオッズと比べて推奨を出します。
- CPU の対戦相手（堅実／攻撃的／コール好き／バランス／ルーズ）は、同じコーチの判断に性格ごとのブレを加えて行動します。

## ファイル構成

```
index.html           画面
css/style.css        スタイル
js/cards.js          カードと役判定
js/glossary.js       用語集と自動リンク
js/audio.js          BGM と効果音（Web Audio で合成）
js/characters.js     キャラクターの似顔絵（SVG）とセリフ
js/equity.js         チェン・スコア、ドロー検出、勝率計算
js/advisor.js        コーチ（推奨アクションと理由）
js/bots.js           CPU プレイヤー
js/game.js           進行エンジン（ブラインド、ベッティング、サイドポット、ショーダウン）
js/ui.js             描画と操作
tests/engine.test.mjs エンジンのテスト
scripts/build-single.mjs 1ファイルにまとめたHTMLを出力
```

## テスト

```
node tests/engine.test.mjs
```

役判定、勝率計算、ドロー検出、そして数百ハンドの自動対局でチップ総量が保存されることを確認します。
