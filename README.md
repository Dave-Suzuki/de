# ホールデム道場

テキサスホールデム（ノーリミット）を CPU 相手に打ちながら学べるブラウザアプリです。
ビルド不要で、`index.html` をブラウザで開くだけで動きます。

## 3つのモード

| モード | 内容 |
| --- | --- |
| **プリフロップ特訓** | 配られた2枚とポジションを見て、フォールド／コール／レイズを即答。答えるとすぐ採点して理由を解説します。「ヒントを見る」で先にアドバイスを見ることもできます。 |
| **ライブコーチ** | 1ハンドをリバーまで通してプレイ。自分の番になるたびに、推奨アクション・推定勝率・ポットオッズ・ドローを表示します。ハンド終了後には振り返りも出ます。 |
| **レビュー** | プレイ中のヒントはなし。ハンド終了後に、一つひとつの判断を「推奨」「こうすべきだった」「実際の勝率（相手の手札が見えていた場合）」と一緒に振り返ります。 |

各判断は「ナイス判断／許容範囲／改善しよう」で採点され、ヘッダーに累計の正解率と収支（BB）が出ます。
キーボードでは F（フォールド）、C（チェック／コール）、R（ベット／レイズ）、N（次のハンド）が使えます。

## コーチの考え方

- **プリフロップ**：チェン・フォーミュラでハンドを点数化し、ポジション別の参加基準（UTG 9点、HJ 8点、CO 7点、BTN 6点…）で判断。レイズへの対応（3ベット／コール／フォールド）、BB のディフェンス、ポケットペアのセットマイニングも考慮します。
- **フロップ以降**：モンテカルロ法で推定勝率を計算します。相手のハンドは、プリフロップの行動（レイズ・コール・リンプ）から推定したレンジと、そのストリートでベットしたかどうかで絞り込みます。その勝率を、ポットオッズ・ドローのアウツ（2と4の法則）・インプライドオッズと比べて推奨を出します。
- CPU の対戦相手（堅実／攻撃的／コール好き／バランス／ルーズ）は、同じコーチの判断に性格ごとのブレを加えて行動します。

## ファイル構成

```
index.html           画面
css/style.css        スタイル
js/cards.js          カードと役判定
js/equity.js         チェン・スコア、ドロー検出、勝率計算
js/advisor.js        コーチ（推奨アクションと理由）
js/bots.js           CPU プレイヤー
js/game.js           進行エンジン（ブラインド、ベッティング、サイドポット、ショーダウン）
js/ui.js             描画と操作
tests/engine.test.mjs エンジンのテスト
scripts/build-single.mjs 1ファイルにまとめたHTMLを出力
```

## テスト

```
node tests/engine.test.mjs
```

役判定、勝率計算、ドロー検出、そして数百ハンドの自動対局でチップ総量が保存されることを確認します。
